co_win32_clock_0
================

Clock showing the system time (UTC) of Windows.

.. code-block:: c

   #include <co/win32/clock_0.h>

Includes ``co/clock_0.h``. Create it with ``co_win32_clock_0_create_0()``; its handle may be cast to ``co_clock_0``.
